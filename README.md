# Hi, I'm Sam

I build practical AI tools for professional services businesses: document intelligence, workflow automation, and operational systems backed by specialist knowledge in NZ accounting, tax, and compliance.

## What I Build

- Domain-specific RAG and document search systems with citations, retrieval evaluation, and grounding checks.
- Workflow automation for messy business processes, internal tools, dashboards, and scheduled operations.
- AI-assisted development systems using Codex, Claude Code, MCP tools, regression tests, and multi-model review loops.

## Featured Projects

### NZ Tax RAG

Retrieval-augmented generation over NZ tax legislation, IRD guidance, and case law.

Commercial angle: helps professional-services teams ask cited questions over complex tax material while separating retrieval quality, grounding quality, and final answer quality.

Highlights:

- section-aware chunking for legislation
- hybrid dense/BM25 retrieval
- reranking
- citation and grounding checks
- evaluation-focused design

### NOCSCOUT Discord Bot and Dashboard

Discord automation and desktop dashboard for coordinating world-boss scouting.

Commercial angle: turns a chat-heavy coordination process into a tracked operational workflow with self-service commands, state, scheduler logic, and an operator dashboard. It is no longer deployed, but remains useful as an internal-tools case study.

Highlights:

- Discord slash commands and persistent buttons
- SQLite state and migrations
- 25-minute warning / 28-minute expiry flow
- FastAPI dashboard API
- regression tests for service and scheduler behavior

### Otago Deerstalkers Website

Static website and publishing automation for the NZDA Otago Branch.

Commercial angle: demonstrates small-business automation: Vercel hosting, GitHub Actions, Google Sheets timetable publishing, and newsletter generation.

Highlights:

- static site delivery
- automated range timetable sync
- newsletter publishing workflow
- Cloudflare Email Worker prototype
- maintainable content scripts
